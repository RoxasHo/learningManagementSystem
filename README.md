# Learning Management System (LMS)

This is a **Learning Management System (LMS)** built using **PHP's Laravel framework**, with **MySQL** as the database and **Apache** as the web server. The system provides a platform for managing users, courses, and discussions, making learning more accessible and interactive.  

## 📌 Features
This LMS consists of **four core modules**:
1. **User Management Module** – Handles user authentication, roles, and permissions.
2. **Course Front Module** – Displays courses to students and allows enrollment.
3. **Course Management Module** – Enables course creation, updates, and organization.
4. **Forum Module** – Facilitates discussions and knowledge sharing among users.  

## 🚀 Getting Started  

### **Prerequisites**
Make sure you have the following installed:  
- **PHP** (Laravel requires PHP 8 or later)  
- **Composer** (PHP dependency manager)  
- **XAMPP** (for Apache and MySQL)  

### **Installation Steps**
1. Clone the repository:
   ```bash
   git clone https://github.com/RoxasHo/learningManagementSystem
2. Navigate into the project directory:
    ```bash
    cd learningManagementSystem
3. Install dependencies:
    ```bash
    composer install
4. Set up environment variables:
    ```bash
    cp .env.example .env
    php artisan key:generate
5. Run database migrations:
    ```bash
    php artisan migrate
6. Start the development server:
    ```bash
    php artisan serve
7. Open your browser and visit:
    ```bash
    http://127.0.0.1:8000
